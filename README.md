Что делает программа?
Представляет собой простую социальную сеть, в которой пользователь может создать профиль, добавлять посты, ставить лайки и оставлять комментарии.

Как её запустить?
Открыть HTML-файл в браузере.

Какой результат получили?
Получился базовый прототип социальной сети с основными функциями взаимодействия между пользователями.
