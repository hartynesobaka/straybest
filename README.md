Программа представляет собой простую социальную сеть, в которой пользователь может создать профиль, добавлять посты, ставить лайки и оставлять комментарии.
Открывается через HTML-файл в браузере.
Получился базовый прототип социальной сети с основными функциями взаимодействия между пользователями.
